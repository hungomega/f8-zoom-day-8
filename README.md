# Yêu cầu chung

Tiếp tục sửa vào repo của bài tập trước.


# 1. Áp dụng kiến thức mới hoàn thiện các pages

Sử dụng page trong bài tập buổi 7.

Áp dụng các kiến thức học trong buổi 8 và hoàn thiện page trên.

Các kiến thức bao gồm:

- Postition
- Transition
- Transform


# 2. Xây dựng danh sách chương và bài học

Tham khảo bất cứ danh sách chương và bài học của khóa học bất kỳ trên internet (hoặc tự xây dựng, nhờ AI lên danh sách, …).

Tạo file `outline-course.html` sử dụng cấu trúc `ul...li` lồng nhau xây dựng danh sách chương và bài học.

Đảm bảo tên chương được sticky giúp tối ưu trải nghiệm người dùng khi duyệt danh sách bài học.

Tham khảo UI trên internet và tự CSS sao cho dễ nhìn và sạch sẽ.


# 3. Hoàn thiện chương học “Các thuộc tính CSS khác”

Hoàn thiện các bài học trong chương phía sau.

Sau đó, hoàn thiện toàn bộ các Flashcards.

Nộp bài bao gồm:

- Link Github Repo
- Github Pages
- Ảnh chụp hoàn thiện phần Flashcards
